🔌 Snapcast (Multi-room audio)

Stores connection settings for a Snapcast server on your network so this app can duck/restore its volume during azan. This saves the settings below; it does not yet route azan audio through Snapcast itself - that would need Snapcast installed and configured separately.

How long to wait after the audio finishes decoding before restoring volume, to cover Snapcast's own buffering plus any extra latency a cast-connected speaker adds on top. If you can still hear the volume jump up near the very end of a dua/azan, increase this.

📺 Fire TV Display

Your Fire TV's display address (enter this in the Smart Azan TV app, or in any other browser/kiosk app you point at the TV):

{{ tv_display_url }}

This is a separate, plain-HTTP address from the main https:// one you use in a browser - deliberately so, since a TV app polling for a new azan over a self-signed HTTPS certificate can silently fail even though the page itself loads fine. No certificate warning to accept, nothing else to configure - just enter the address above.

Using Fully Kiosk Browser instead

If you'd rather use Fully Kiosk Browser (a paid/ad-supported third-party app) so this app can also auto-wake the TV and switch away from whatever else is showing at azan time:

  1. In Fully Kiosk's settings on the Fire TV: enable Remote Administration, set a password, and note the IP address/port it shows (default port 2323).
  2. Also enable Autoplay of Videos/Audio in Fully Kiosk's Web Content settings, so the azan actually plays without needing a tap.
  3. Enter that Fully Kiosk address below and save.

Using the Smart Azan TV app instead

If you installed our own Smart Azan TV app on the Fire TV (rather than Fully Kiosk), this wakes that Fire TV via adb for azan and puts it back to sleep afterward - but only if it was actually asleep to begin with, so it's never turned off while someone's watching it. Needs adb on this Pi (already the case if you've sideloaded the app), and "ADB debugging" + "Always allow from this computer" enabled on that Fire TV once.

Comma-separated if you have more than one Fire TV running the app. Find Fire TVs above fills this in for you.

Advanced: TVs on a different network than this machine

Only if your TVs are on a separate network this machine can't reach (for example behind a second router): run tv_wake_helper.py on a machine that is on the TVs' network and enter its address here. Leave blank for a normal home with one network.
